# Лабораторна чи практична

Звіт складається з титульної сторінки, заголовка з темою роботи і вашого тексту. Приклади нижче розраховані на [mise](install.md#mise-рекомендовано); якщо пакунок встановлено локально, імпортуйте `@local/nure:0.3.0` замість `@vendor/nure:0.3.0`.

## Повний приклад

`src/doc.toml`:
```toml
subject = "СМП"
type = "ЛБ"
number = 2

[[authors]]
name = "Косач Л. П."
edu-program = "КУІБ"
group = "24-1"
gender = "f"
variant = 8

[[mentors]]
name = "Шевченко Т. Г."
degree = "Доцент кафедри ПІ"
gender = "m"

[[mentors]]
name = "Франко І. Я."
degree = "Асистент кафедри ПІ"
gender = "m"
```

`src/main.typ`:
```typst
#import "@vendor/nure:0.3.0": *
#import style: spacing

#let w = work(..toml("doc.toml"), title: "Потік керування та алгоритмічні структури Bash")

#set document(..w.document)
#show: style.dstu.with(skip: 1)

#report.title-page(w)
#title-heading(w)

#v(-spacing)
== Мета роботи
Ознайомитися з умовними операторами й циклами Bash.

== Хід роботи
#v(-spacing)
=== Підготовка
...

=== Виконання
...

== Висновки
У ході роботи ...

== Контрольні запитання
...

#show: style.appendices
= Код програми
```

Розберемо, що тут відбувається.

## Дані роботи: `work`

```typst
#let w = work(..toml("doc.toml"), title: "...")
```

`work` збирає все, що потрібно для титулки: університет, кафедру, дисципліну, тип і номер роботи, авторів, викладачів. Дані беруться з `doc.toml`, а тему зручно писати прямо в `main.typ` -- вона своя для кожної роботи. Можна й навпаки: тема в `doc.toml` (`title = "..."`), а в `main.typ` просто `work(..toml("doc.toml"))`.

Повна назва дисципліни, кафедра й спеціальність підставляються самі за скороченнями (`subject = "СМП"`, `edu-program = "КУІБ"`). Якщо вашої дисципліни немає у вбудованих даних, на титулці буде скорочення -- як додати повну назву, див. [Дані роботи](data.md#власні-дисципліни-й-університети).

Усі поля -- у [Дані роботи](data.md).

## Оформлення: `style.dstu`

```typst
#set document(..w.document)
#show: style.dstu.with(skip: 1)
```

Перший рядок записує тему й авторів у властивості PDF. Другий вмикає оформлення за ДСТУ 3008:2015: поля, Times New Roman 14 pt, інтервали, абзацний відступ, заголовки, нумерацію рисунків і таблиць за розділами тощо (докладно -- у [Оформлення тексту](writing.md)).

`skip: 1` -- скільки перших сторінок лишити без номера: титулка не нумерується, але враховується, тож наступна сторінка має номер 2. Для курсових див. [Курсова](coursework.md).

## Титульна сторінка: `report.title-page`

```typst
#report.title-page(w)
```

Є два варіанти оформлення:

| `layout` | Вигляд |
| --- | --- |
| `"default"` | Міністерство, університет, кафедра; «Звіт з лабораторної роботи №N з дисципліни … з теми …»; ліворуч «Виконала: ст. гр. …, ПІБ, Варіант», праворуч «Перевірив: посада, ПІБ»; унизу «Харків – рік» |
| `"complex"` | Те саме плюс спеціальність і освітня програма в шапці; варіант під темою; виконавці й перевіряючі праворуч з підписами «(прізвище та ініціали)» |

```typst
#report.title-page(w, layout: "complex")
```

Тип роботи визначає заголовок: `ЛБ` -- «Звіт з лабораторної роботи», `ПЗ` -- «Звіт з практичної роботи», `КР` -- «Контрольна робота», `РФ` -- «Реферат», `ІДЗ` -- «Індивідуальне домашнє завдання». Будь-який інший текст у `type` виводиться як є. «Виконав/Виконала/Виконали» і «Перевірив/Перевірила/Перевірили» обираються за полем `gender` і кількістю людей.

### Змінити частину титулки

Титулка складається з чотирьох частин -- слотів:

| Слот | Що в ньому |
| --- | --- |
| `header` | Міністерство, університет, кафедра |
| `info` | Тип і номер роботи, дисципліна, тема |
| `credentials` | Хто виконав і хто перевірив |
| `footer` | Місто й рік |

Кожен слот можна замінити своїм вмістом або прибрати через `none`:

```typst
#report.title-page(
  w,
  footer: [Київ -- 2026],
  credentials: [Виконала: ст. гр. КУІБ-24-1 Косач Л. П.],
)
```

Вміст за замовчуванням доступний як функції `default-header(w)`, `default-info(w)`, `default-credentials(w)`, `default-footer(w)` у модулях `report.nure` (варіант `"default"`) і `report.complex`. Так зручно щось дописати, не переписуючи решту:

```typst
#report.title-page(w, info: [#report.nure.default-info(w) \ Підгрупа 2])
```

## Заголовок з темою: `title-heading`

```typst
#title-heading(w)
```

Вставляє заголовок першого рівня з темою роботи, пронумерований номером роботи: для `number = 2` вийде «2 ПОТІК КЕРУВАННЯ …», а підрозділи `==` нумеруватимуться 2.1, 2.2 і т. д.

- Якщо теми немає (`title: none`), заголовок не вставляється, а підрозділи однаково нумеруються від номера роботи.
- Якщо такий заголовок не потрібен, просто не викликайте `title-heading` і починайте з власного `= ...`.
- Тема-рядок обробляється як розмітка Typst, тож у ній можна писати, наприклад, `_курсив_`.

## Текст роботи

Розділи -- звичайні заголовки Typst: `==` для «Мета роботи», «Хід роботи», `===` для пунктів усередині. `#v(-spacing)` прибирає подвійний інтервал, коли заголовок іде одразу після іншого заголовка (шаблон не може визначити це сам).

Рисунки, таблиці, код, формули, посилання -- у [Оформлення тексту](writing.md).

Велику роботу зручно розбити на файли:

```typst
#include "chapters/task1.typ"
#include "chapters/task2.typ"
```

У кожному такому файлі, якщо він використовує функції пакунка, теж потрібен імпорт: `#import "@vendor/nure:0.3.0": *`.

## Додатки

```typst
#show: style.appendices

= Код програми
```

Усе після `#show: style.appendices` -- додатки: заголовок першого рівня стає «ДОДАТОК А» з назвою нижче, рисунки й таблиці всередині нумеруються «А.1». Детальніше -- у [Оформлення тексту](writing.md#додатки).

## Здача

`mise run rename` збирає PDF і копіює його з назвою на кшталт `ЛБ2_Косач_КУІБ-24-1_СМП.pdf` (з `doc.toml`; очікує ім'я у форматі «Прізвище І. Б.»).

## Коротший варіант: рецепт `pz-lb`

Те саме, що титулка + заголовок + стилі, одним рядком:

```typst
#import "@vendor/nure:0.3.0": *

#show: pz-lb.with(..toml("doc.toml"), title: "Потік керування та алгоритмічні структури Bash")

== Мета роботи
...
```

`pz-lb` приймає поля `doc.toml` (`university`, `edu-program`, `subject`, `type`, `number`, `title`, `authors`, `mentors`), а також `layout`, слоти титулки (`footer: ...`) і `skip-heading: true`, щоб не вставляти заголовок з темою. Власних даних (`data`) чи року (`year`) він не приймає. Зручно для простих робіт; якщо треба більше -- переходьте на варіант вище.
