# Розширення

Документ збирається з окремих функцій, тож будь-яку сторінку можна замінити своєю, а нові -- дописати поруч. Пакунок при цьому правити не треба.

## Як це влаштовано

- `work(...)` повертає звичайний словник з даними роботи (`w`).
- Кожен блок -- функція, що приймає `w` і повертає вміст: `report.title-page(w)`, `cw.task(w, ...)`. Блоки не мають прихованого стану: результат залежить лише від аргументів.
- Стилі (`style.dstu`, `style.appendices`) -- show-правила, які ви застосовуєте самі.
- Рецепти (`pz-lb`, `coursework`, `coursework-v2`) -- це просто композиції блоків. Їхній вміст -- у [src/recipes.typ](../src/recipes.typ); скопіюйте його в документ, якщо треба змінити порядок сторінок.

## Власна сторінка

Власна сторінка -- звичайна функція від `w`. Поля `w` описано в [Довіднику](reference.md#дані), а поля форм з офіційних сторінок доступні через модуль `forms`:

```typst
#let approval-sheet(w) = {
  align(center, utils.bold[АРКУШ ПОГОДЖЕННЯ])
  v(1em)
  forms.label-line([Здобувач], w.authors.first().name, caption: [(прізвище та ініціали)], label-width: 90pt)
  v(1em)
  forms.label-line([Керівник], w.mentors.first().name, caption: [(прізвище та ініціали)], label-width: 90pt)
  pagebreak()
}

#cw.title-page(w)
#approval-sheet(w)
#cw.task(w, source: [...], content: [...], graphics: [...])
```

Тримайте такі функції в `utils.typ` проєкту й імпортуйте в `main.typ`: `#import "utils.typ": *`.

| `forms.*` | Що це |
| --- | --- |
| `label-line(label, value, caption: none, label-width: auto)` | Назва і підкреслене поле, за потреби з підписом під ним |
| `inline-label-line(label, value)` | Те саме, але підкреслено кожен рядок при переносі |
| `note(content)` | Дрібний підпис під полем: «(повна назва)» |
| `form-field(alignment: center, content)` | Однорядкове підкреслене поле |
| `task-head-fields(fields)` | Сітка рядків «назва -- поле», як у шапці завдання |
| `task-num(n)` | «1.» -- номер пункту завдання |
| `title-field(value)` | Поле теми з підписом «(тема)» |
| `commission-lines(members)` | Лінії для підписів членів комісії |

## Власна титулка

Для дрібних змін вистачає [слотів](lab.md#змінити-частину-титулки). Якщо змінити треба все, передайте всі чотири слоти -- від макета лишиться тільки розкладка (шапка вгорі, підписи посередині, рядок унизу):

```typst
#report.title-page(
  w,
  header: [#upper(w.uni.name) \ Кафедра #w.edu.department-gen],
  info: [Розрахунково-графічна робота \ з дисципліни «#w.subject-name»],
  credentials: report.nure.default-credentials(w),
  footer: [Харків -- #w.year],
)
```

Або напишіть сторінку повністю, як у прикладі з аркушем погодження вище.

## Свій вигляд тексту

Встановлені після `#show: style.dstu` правила `set` і `show` діють поверх оформлення пакунка:

```typst
#show: style.dstu.with(skip: 1)

#set text(font: "Liberation Serif")         // інший шрифт
#set par(leading: 1.2em)                    // інший інтервал
#show heading.where(level: 3): set text(style: "italic")
```

## Свої дані

Дисципліни, освітні програми й університети, яких немає в пакунку, додаються через `data.yaml` -- див. [Дані роботи](data.md#власні-дисципліни-й-університети). У `w` можна додати й свої поля: `work(...) + (consultant: "Драч І. Ф.")`.

## Поділитися з іншими

Якщо ваша дисципліна, освітня програма чи нова сторінка знадобиться іншим -- запропонуйте її в репозиторій: дані -- у [src/config/universities.yaml](../src/config/universities.yaml), блоки -- у `src/parts/`. Як влаштований код і як перевірити зміни, див. [Розробка](development.md).
