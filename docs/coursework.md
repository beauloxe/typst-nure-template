# Курсова

Пакунок підтримує два варіанти пояснювальної записки:

| | Модуль | Перелік джерел | Повний приклад |
| --- | --- | --- | --- |
| Курсова робота | `cw` | ДСТУ 3008:2015 | [template/default/coursework.typ](../template/default/coursework.typ) |
| Комплексний курсовий проєкт (нова форма ХНУРЕ) | `cw-v2` | ДСТУ 8302:2015 | [template/default/coursework-v2.typ](../template/default/coursework-v2.typ) |

Обидва збираються з тих самих частин: титульна сторінка, завдання, календарний план, реферат, зміст, основний текст, перелік джерел, додатки. Ви викликаєте потрібні блоки по черзі. Титулка, завдання й календарний план самі закінчуються розривом сторінки; після реферату нову сторінку починає заголовок змісту.

## Дані

Крім звичайних полів (див. [Дані роботи](data.md)), курсовим потрібні:

| Поле | Де | Навіщо |
| --- | --- | --- |
| `initial-date`, `done-date` | `doc.toml` або `work(...)` | Дата видачі завдання і термін здачі; рік з `done-date` іде на титулку |
| `course`, `semester` | автор | Курс і семестр на сторінці завдання |
| `full-name-gen` | автор | ПІБ у родовому відмінку: «Косач Лариси Петрівни» |
| `full-name-dat` | автор, лише `cw-v2` | ПІБ у давальному: «Косач Ларисі Петрівні» (за замовчуванням -- `full-name-gen`) |
| `display-name` | автор і викладачі, лише `cw-v2` | «Лариса КОСАЧ» -- форма «Власне ім'я ПРІЗВИЩЕ» (за замовчуванням -- `name`) |
| `committee-members` | `doc.toml` або `work(...)`, лише `cw-v2` | Члени комісії; за замовчуванням -- усі викладачі, крім першого |

Перший викладач у `mentors` -- керівник роботи.

Дати можна писати в `doc.toml` -- без лапок, тоді Typst прочитає їх як дати. Як і інші поля роботи, вони мають стояти на початку файлу, до першого `[[authors]]` чи `[[mentors]]` (див. [Дані роботи](data.md#формат-doctoml)):

```toml
subject = "БД"
initial-date = 2026-09-15
done-date = 2026-12-27

[[authors]]
...
```

або прямо в `main.typ`:

```typst
#let w = work(
  ..toml("doc.toml"),
  title: "Інформаційна система «Помічник класного керівника»",
  initial-date: datetime(year: 2026, month: 9, day: 15),
  done-date: datetime(year: 2026, month: 12, day: 27),
)
```

## Курсова робота (`cw`)

```typst
#import "@vendor/nure:0.3.0": *

// initial-date і done-date -- у doc.toml
#let w = work(..toml("doc.toml"), title: "Інформаційна система «Помічник класного керівника»")

#set document(..w.document)
#show: style.dstu.with(skip: 1)

#cw.title-page(w)

#cw.task(
  w,
  source: [методичні вказівки, вимоги до системи, ...],
  content: [вступ, аналіз предметної області, ...],
  graphics: [діаграма класів, ER-діаграма, ...],
)

#cw.calendar-plan(w, table(
  columns: 4,
  align: (center, left, center, center),
  [№], [Назва етапів], [Строк виконання], [Примітки],
  [1], [Аналіз предметної області], [15.09 -- 24.09], [Виконано],
  [2], [Проєктування бази даних], [24.09 -- 18.10], [Виконано],
))

#cw.abstract(w, keywords: ("база даних", "веб-застосунок", "GO", "SQL"))[
  Мета роботи -- ...
]

#cw.contents()

#utils.nheading[Вступ]
...

= Аналіз предметної області
...

#utils.nheading[Висновки]
...

#dstu-bibliography(path("bibl.yml"), style: "3008")

#show: style.appendices
= Код програми
...
```

| Блок | Сторінка |
| --- | --- |
| `cw.title-page(w)` | Титулка: «Пояснювальна записка до курсової роботи», тема, виконавець, керівник, комісія (усі викладачі) |
| `cw.task(w, source:, content:, graphics:)` | Завдання: кафедра, дисципліна, спеціальність, курс, група, семестр, пункти 1–6 з датами |
| `cw.calendar-plan(w, table, approval-date: auto)` | Календарний план: ваша таблиця й підписи з датою затвердження (за замовчуванням -- `done-date`) |
| `cw.abstract(w, keywords: (...))[текст]` | Реферат: підсумки документа, ключові слова великими літерами, текст |
| `cw.contents()` | Зміст |

## Комплексний курсовий проєкт (`cw-v2`)

```typst
#import "@vendor/nure:0.3.0": *

#let w = work(
  ..toml("doc.toml"),
  title: ("Демонстраційна інформаційна система для комплексного ", "курсового проєкту"),
  committee-members: (
    (name: "Сосюра В. М.", degree: "Доц."),
    (name: "Симоненко В. А.", degree: "Ст. викл."),
  ),
  initial-date: datetime(year: 2026, month: 9, day: 15),
  done-date: datetime(year: 2026, month: 12, day: 27),
)

#set document(..w.document)
#show: style.dstu.with(skip: 1)

#cw-v2.title-page(w)

#cw-v2.task(
  w,
  source: ([Узагальнити модель предметної області,], [визначити основні сутності.]),
  content: ([Опис предметної галузі, формування вимог,], [проєктування, тестування.]),
)

#cw-v2.calendar-plan(w, table(
  columns: (0.7fr, 5.8fr, 2.5fr, 1.6fr),
  [№], [Назва етапів роботи], [Термін виконання], [Примітка],
  [1], [Аналіз предметної галузі], [], [виконано],
))

#cw-v2.abstract(
  w,
  keywords: (("веб-застосунок", "WEB APPLICATION"), ("курсова робота", "COURSEWORK")),
)[
  Мета даної роботи -- ...
][
  The purpose of this work is ...
]

#cw-v2.contents()

= Моделювання
...

#dstu-bibliography(path("bibl.yml"), style: "8302")

#show: style.appendices
= Приклад звіту
...
```

| Блок | Сторінка |
| --- | --- |
| `cw-v2.title-page(w)` | Титулка за новою формою: факультет, кафедра, рівень вищої освіти, тема, здобувач, спеціальність, освітня програма, керівник, члени комісії |
| `cw-v2.task(w, source:, content:)` | Завдання |
| `cw-v2.calendar-plan(w, table)` | Календарний план, дата видачі завдання (`initial-date`) і підписи |
| `cw-v2.abstract(w, keywords: (...))[укр][англ]` | Реферат, за потреби двомовний (заголовок стає «РЕФЕРАТ / ABSTRACT») |
| `cw-v2.contents()` | Зміст, де додатки подано як «Додаток А Назва» без підрозділів |

Особливості:
- **Тема масивом рядків.** На сторінці завдання кожен елемент масиву -- окремий підкреслений рядок, а на титулці вони з'єднуються. Пробіл на стику пишіть у кінці першого рядка, як у прикладі. Звичайний рядок теж працює.
- **`source` і `content` масивом** так само розбиваються на підкреслені рядки.
- **Ключові слова** -- або пари `(укр, англ)`, або рядки, а англійські окремо: `keywords: ("тест", "шаблон"), en-keywords: ("test", "template")`.
- Поля `faculty`, `education-level`, `program-type`, `program-name` у `work` мають типові значення для ХНУРЕ («комп'ютерних наук», «перший (бакалаврський)», «освітньо-професійна», назва освітньої програми); змінюйте їх за потреби.

## Нумерація сторінок

`style.dstu.with(skip: 1)` лишає без номера лише титулку; решта сторінок, разом із завданням і рефератом, нумерується від 2. Якщо на вашій кафедрі вимагають інакше, змініть `skip` (кількість сторінок без номера) або `offset` (зсув номерів).

## Підсумки в рефераті

Рядок «Пояснювальна записка містить: N с., N табл., N рис., N джерел» рахується автоматично:
- **сторінки** -- усі сторінки документа;
- **таблиці** -- усі таблиці-`figure` (зокрема `dstu-table`);
- **рисунки** -- `figure(image(...))`, зокрема через `dstu-figure`;
- **джерела** -- різні джерела, на які є посилання `@ключ` у тексті.

Перелік джерел за замовчуванням виводить усі записи з `bibl.yml`, а в підсумку враховуються лише процитовані. Щоб числа збігалися, цитуйте кожне джерело або передайте `full: false` у `dstu-bibliography` -- тоді в перелік потраплять лише процитовані.

Нульові значення пропускаються.

## Вступ і висновки

«Вступ», «Висновки» та інші ненумеровані розділи пишіть через `#utils.nheading[Вступ]` -- це заголовок першого рівня без номера, і він з'являється у змісті.

## Коротший варіант: рецепти

Обидва варіанти доступні й одним викликом -- з тими самими даними, згрупованими у словники:

```typst
#show: coursework.with(
  title: "...",
  subject: "БД",
  authors: (...),
  mentors: (...),
  task-list: (done-date: ..., initial-date: ..., source: [...], content: [...], graphics: [...]),
  calendar-plan: (plan-table: table(...), approval-date: ...),
  abstract: (keywords: (...), text: [...]),
  bib-path: path("bibl.yml"),
  appendices: [= Код програми ...],
)

= Розділ 1
...
```

`coursework-v2` аналогічний, додатково приймає `committee-members`, `abstract-en: (keywords: ..., text: ...)`, `faculty`, `education-level`, `program-type`, `program-name`. Додатки в рецептах передаються аргументом `appendices`, бо перелік джерел мусить стояти перед ними.

Рецепт зручний, поки не треба нічого змінювати. Щоб, наприклад, прибрати календарний план чи вставити свою сторінку, використовуйте блоки, як вище: вміст рецептів -- у [src/recipes.typ](../src/recipes.typ).
