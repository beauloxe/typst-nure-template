# Дані роботи

Усе, що потрапляє на титулки й службові сторінки, описується один раз і передається у `work`:

```typst
#let w = work(..toml("doc.toml"), title: "...")
```

`..toml("doc.toml")` підставляє всі поля файлу як аргументи `work`; поля можна писати й прямо в `work(...)` -- це те саме.

## Формат `doc.toml`

```toml
subject = "СМП"            # поля роботи -- на початку файлу
type = "ЛБ"
number = 2

[[authors]]                # далі автори
name = "Косач Л. П."
...

[[mentors]]                # і викладачі
name = "Шевченко Т. Г."
...
```

Поля роботи (`subject`, `type`, дати тощо) пишіть **до** першого `[[authors]]` чи `[[mentors]]`: у TOML усе, що стоїть після заголовка `[[...]]`, належить цьому блоку. Поле, дописане в кінець файлу, тихо потрапить до останнього викладача, і `work` його не побачить.

Дати пишіть без лапок (`done-date = 2026-12-27`) -- тоді це дата, а не рядок.

## Поля роботи

| Поле | Приклад | Опис |
| --- | --- | --- |
| `university` | `"ХНУРЕ"` | Код університету, за замовчуванням `"ХНУРЕ"` |
| `edu-program` | `"КУІБ"` | Освітня програма; за замовчуванням -- першого автора |
| `subject` | `"СМП"` | Скорочення дисципліни; повна назва береться з даних, невідоме скорочення виводиться як є |
| `type` | `"ЛБ"` | `ЛБ`, `ПЗ`, `КР`, `РФ`, `ІДЗ` або будь-який текст |
| `number` | `2` | Номер роботи |
| `title` | `"Потік керування"` | Тема; для курсового проєкту можна масивом рядків (див. [Курсова](coursework.md)) |
| `authors` | | Автори, див. нижче |
| `mentors` | | Викладачі, див. нижче; перший -- керівник |
| `committee-members` | | Члени комісії (лише курсовий проєкт); за замовчуванням -- усі викладачі, крім першого |
| `initial-date`, `done-date` | `2026-09-15` | Дати видачі й здачі завдання (курсові) |
| `year` | `2026` | Рік на титулці; за замовчуванням -- з `done-date` або поточний |
| `faculty` | `"комп'ютерних наук"` | Факультет (курсовий проєкт) |
| `education-level` | `"перший (бакалаврський)"` | Рівень вищої освіти (курсовий проєкт) |
| `program-type` | `"освітньо-професійна"` | Тип програми (курсовий проєкт) |
| `program-name` | | Назва освітньої програми (курсовий проєкт); за замовчуванням -- з даних програми |
| `data` | `yaml("data.yaml")` | Власні дисципліни, програми, університети, див. [нижче](#власні-дисципліни-й-університети) |

## Автори

```toml
[[authors]]
name = "Косач Л. П."
edu-program = "КУІБ"
group = "24-1"
gender = "f"
variant = 8
course = 2
semester = 4
full-name-gen = "Косач Лариси Петрівни"
full-name-dat = "Косач Ларисі Петрівні"
display-name = "Лариса КОСАЧ"
```

| Поле | Обов'язкове | Де використовується |
| --- | --- | --- |
| `name` | так | Скрізь: «Прізвище І. Б.» |
| `edu-program` | так | Шифр групи, кафедра, спеціальність |
| `group` | так | Шифр групи: `"24-1"` разом з `edu-program` дає «КУІБ-24-1»; можна писати й повністю `"КУІБ-24-1"` |
| `gender` | так | `"m"` -- «Виконав», `"f"` -- «Виконала»; для кількох авторів -- «Виконали» |
| `variant` | ні | «Варіант №8» на титулці звіту |
| `course`, `semester` | курсові | Сторінка завдання |
| `full-name-gen` | курсові | ПІБ у родовому відмінку (завдання) |
| `full-name-dat` | ні | ПІБ у давальному відмінку (завдання курсового проєкту); за замовчуванням -- `full-name-gen` |
| `display-name` | ні | «Власне ім'я ПРІЗВИЩЕ» на титулці курсового проєкту; за замовчуванням -- `name` |

Кількох авторів записуйте кількома блоками `[[authors]]`: на титулці звіту з'являться всі, у курсових використовується перший.

## Викладачі

```toml
[[mentors]]
name = "Шевченко Т. Г."
degree = "Доцент кафедри ПІ"
gender = "m"
display-name = "Тарас ШЕВЧЕНКО"
```

| Поле | Обов'язкове | Опис |
| --- | --- | --- |
| `name` | так | «Прізвище І. Б.» |
| `degree` | ні | Посада, звання |
| `gender` | якщо викладач один | «Перевірив»/«Перевірила»; для кількох -- «Перевірили» |
| `display-name` | ні | «Власне ім'я ПРІЗВИЩЕ» (курсовий проєкт) |

Члени комісії (`committee-members`) мають ті самі поля, крім `gender`.

## Вбудовані дані

[src/config/universities.yaml](../src/config/universities.yaml) містить дані ХНУРЕ: освітні програми ПЗПІ, КУІБ і КНТ (кафедра, спеціальність, код) і понад 80 дисциплін зі скороченнями. Їх можна використовувати й у тексті:

```typst
#w.subject-name               // Скриптові мови програмування
#w.edu.department-gen         // Інфокомунікаційної інженерії ім. В. В. Поповського
#universities.at("ХНУРЕ").subjects.at("БД")   // Бази даних
```

## Власні дисципліни й університети

Якщо вашої дисципліни, освітньої програми чи університету немає у вбудованих даних, не треба правити пакунок. Створіть `data.yaml` поруч із `main.typ` у тому самому форматі:

```yaml
ХНУРЕ:
  subjects:
    ОЗСОС: Основи захисту сучасних операційних систем
  edu-programs:
    ПЗПІ:
      code: F2          # змінити одне поле, решта лишається вбудованою
    ШІ:                 # додати програму
      name-long: Штучний інтелект
      department-gen: Штучного інтелекту
      code: 122
    КНТ: null           # прибрати програму

КПІ:                    # додати університет
  name: Національний технічний університет України «Київський політехнічний інститут імені Ігоря Сікорського»
  edu-programs:
    ІПЗ:
      name-long: Інженерія програмного забезпечення
      department-gen: Інформатики та програмної інженерії
      code: 121
  subjects:
    ОП: Основи програмування
```

і передайте його у `work`:

```typst
#let w = work(..toml("doc.toml"), data: yaml("data.yaml"))
```

Ваші записи накладаються на вбудовані: можна додати нове, змінити окреме поле чи прибрати запис через `null`.

| Запис | Обов'язкові поля | Необов'язкові |
| --- | --- | --- |
| Університет | `name` | `edu-programs`, `subjects` |
| Освітня програма | `name-long`, `department-gen` (кафедра в родовому відмінку), `code` | `description` (спеціальність для макета `"complex"`), `program-name` |

Чого бракує -- `work` повідомить одразу, з назвою поля.

Місто на титулці («Харків») не береться з даних -- для іншого міста замініть слот: `#report.title-page(w, footer: [Київ -- #w.year])`.

## Свої поля

`work` повертає звичайний словник, тож для власних сторінок у нього можна додати будь-що:

```typst
#let w = work(..toml("doc.toml")) + (consultant: "Драч І. Ф.")

Консультант: #w.consultant
```
